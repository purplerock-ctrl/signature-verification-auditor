# Security policy

## Reporting a vulnerability in sigaudit

If you find a security problem **in sigaudit itself** (for example, a way a
crafted profile file, server response or report could compromise the
machine running it, or a leak of the signing secret), please report it
privately via GitHub's **"Report a vulnerability"** button on this
repository's Security tab, rather than in a public issue.

Please include steps to reproduce and the version (`sigaudit --version`).

## Findings in other systems

sigaudit reports misconfigurations in *other* systems' webhook endpoints.
Report those to the owner of that system, following their disclosure policy
or bug bounty program, not to this project.

## Supported versions

Security fixes are made on the latest release.
